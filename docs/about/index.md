# 关于

**王乐圆（Leyuan Wang）**，南开大学物理学院，研究方向是量子信息。更多介绍见个人主页 [leyuanwang.tech](https://leyuanwang.tech)，代码在 GitHub [@foley71047](https://github.com/foley71047)。

这里是我的个人笔记：[笔记](../notes/index.md)记录学习、研究、论文阅读和随想；[定理](../theorems/index.md)是一张随手可查的定理与不等式速查表；[标签](../tags.md)按主题和方法把两者串起来。笔记是自己的学习和思考记录，难免有错，欢迎在 [GitHub](https://github.com/foley71047/notes) 指出。

## 最近在做什么

- **研究**：器件无关（device-independent）认证与网络非局域性——如何在尽量少的假设下，用星型网络认证纠缠测量的纠缠深度。
- **整理中**：量子力学、量子信息基础两套系统的学习笔记（按"直观图像 → 严格定义 → 例题 → 总结"的结构）。
- **课外**：学习量化交易，先把交易机制和风险的算术弄明白。这不是我的专业，笔记仅供参考，不构成投资建议。
