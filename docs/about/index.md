## 本站

"Foley的笔记"是我的个人知识库，分为三个板块：

| 板块 | 内容 |
|---|---|
| [科研](../research/index.md) | 量子信息相关的研究推导、论文阅读与研究总结 |
| [教程](../tutorials/index.md) | 系统性的课程与学习笔记 |
| [兴趣](../interests/index.md) | 学业以外的探索，比如量化交易 |

所有文章都可以按 [标签](../tags.md) 浏览，右上角的搜索支持中文。

本站用 [Zensical](https://zensical.org/) 构建，源文件托管在 [GitHub](https://github.com/foley71047/notes)，每次推送后由 GitHub Actions 自动部署。想看看文章是怎么写的，可以参考 [写作模板](writing-template.md)。

笔记内容是我自己的学习和思考记录，难免有错，欢迎通过 GitHub 指出。
