## 教程的写法

每篇教程尽量遵循同一个结构：**直观图像 → 严格定义 → 带数字的例题 → 一句话总结**。定义、定理、证明、例题用不同颜色的提示框区分，具体写法见 [写作模板](../about/writing-template.md)。
