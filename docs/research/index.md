# 科研

这里记录我在量子信息方向的研究工作：**研究推导**（把一个结论从头推一遍）、**论文阅读**（读懂一篇文章在做什么、凭什么成立）和**研究总结**（把零散的讨论整理成可以反复查阅的框架）。

目前的重点是**器件无关（device-independent）认证**与**网络非局域性**，具体问题是如何在尽量少的假设下认证纠缠测量的纠缠深度。
